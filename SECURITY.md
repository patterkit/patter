# Security

If you find a security problem in Patter, Patterplay, the CLI, or Patterpad, please email
[ian@storytools.se](mailto:ian@storytools.se) rather than opening a public issue, so a fix can ship before
the details are public. Say which package or runtime and version you found it in, and how to reproduce it.

Patter runs stories a writer gave you: a bundle is data, and the runtimes evaluate only the expression
language they define, never arbitrary code. If you find a way to make a runtime do more than that, we'd like
to know.
