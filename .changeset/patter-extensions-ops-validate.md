Validate checks a project's Patter extensions (`ValidateResult.extensions`): each manifest, the project's pins and settings, claims on gameData fields (an error when the project declares the field with another type, a warning when it doesn't declare it), and every value in the extension data against its manifest, with an entry for a node that has gone reported per entry and kept. An error fails `ok` and is an export blocker, so export refuses it; a warning doesn't, and that includes a missing manifest (the data is left as it is), an entry in another scene's shard, and a `.gitattributes` set up for Patter's merge with no rule for `.patterextension`. A pack carries the extensions' manifests, and unpack writes them back; merging a pack back merges extension data by the project's own manifest, and keeps the project's manifest where the pack's differs (`manifestsKept`). `patter init` sets up `.patterextension` shards and manifests for every version control system. `planExtensionUpgrades` takes an extension at its manifest's new version, renaming the stages it renamed in the data and moving the pin in one step, and `runFormat` runs it on a project folder (`FormatResult.notes`). A cast rename follows the name into the data (`renameCastKeys`: map keys and reference values to `cast`, at any depth, by the manifest), the lines (`renameCastInScene`), and the project-level strings keyed by it (`renameCastStrings`, `moveCastKeys`).
