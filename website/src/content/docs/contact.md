PatterKit is made by Ian Thomas. To get in touch, email
[ian@storytools.se](mailto:ian@storytools.se).

Write about anything to do with Patter: a question the docs don't answer, feedback on Patterpad or
the runtimes, a project you're using it on, or something you've seen mentioned here that you'd like
to hear more about.

If you've found a bug, an issue on [GitHub](https://github.com/patterkit/patter/issues) is the
quickest way to get it fixed, and it lets anyone else who hits it follow along.
